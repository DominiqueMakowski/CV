Subset fonts used to set the text of a few logos in img/logos/ that is not
available as official vector artwork. Each holds only the glyphs one wordmark
needs, so they are a few kilobytes each and are of no use for typesetting.

  NotoSans-Regular.subset.ttf       Hopital La Porte Verte   (OFL-NotoSans.txt)
  NotoSans-SemiBold.subset.ttf      Sainte-Anne              (OFL-NotoSans.txt)
  BarlowSemiCondensed-Regular.subset.ttf   SANTE            (OFL-Barlow.txt)

Both families are under the SIL Open Font License 1.1; the licence texts are
alongside. The CV's own typefaces live in cv/fonts/, not here.
